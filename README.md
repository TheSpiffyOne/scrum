# BeanFlow Scrum-доска

Готовый статический сайт для GitHub Pages. Сборка, установка пакетов, сервер и привязка к Sites не нужны.

## Возможности

- 19 историй BeanFlow, 113 Story Points, 6 спринтов.
- Колонки Backlog, Ready, In Progress, Review / Test и Done.
- Перетаскивание карточек и фильтр по спринту.
- Критерии приёмки, приоритеты, зависимости и задачи истории.
- Назначение ответственного и отметка блокировок.
- Ограничения WIP: 3 истории в работе и 2 на проверке.
- Проверка зависимостей перед началом работы и подтверждение готовности.
- Автосохранение в браузере, экспорт и импорт JSON.

Нажмите карточку для просмотра и редактирования деталей. Чтобы начать US02, сначала завершите US01. Переходы идут по цепочке Ready → In Progress → Review / Test → Done; произвольный перенос напрямую в Done не разрешён.

## Сохранение данных

Карточки сохраняются в localStorage вашего браузера на адресе сайта. GitHub Pages публикует сайт, но не синхронизирует изменения между пользователями и не записывает карточки обратно в репозиторий. На другом устройстве или в другом браузере откроется исходный учебный план. Для переноса используйте **Экспорт JSON** и **Импорт JSON**; периодически сохраняйте резервную копию. При смене адреса сайта, очистке данных браузера или режиме инкогнито состояние может быть недоступно.

Публично доступная страница показывает исходные истории, включённые в `index.html`; локальные изменения отдельного пользователя автоматически на сайт не отправляются.

## Локальный запуск

Откройте `index.html` в актуальном браузере. В режиме локального файла браузер может ограничить автосохранение; после публикации на GitHub Pages используйте адрес HTTPS.

## Состав

- `index.html` — вся доска, оформление, логика и исходные истории в одном файле.
- `.nojekyll` — отключение обработки Jekyll при публикации из ветки.
- `README.md` — эта инструкция.

Токенов, паролей, настройки Sites, личных файлов отчёта и внешних библиотек в пакете нет.
